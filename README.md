# TurnoSimple

Agenda visual para gestionar turnos, clientes y ocupación semanal.

## Funciones

- Vista semanal por día y horario.
- Alta de nuevos turnos con servicio y valor estimado.
- Indicadores de ocupación, facturación y actividad.
- Buscador de clientes y servicios.
- Resumen de turnos del día.
- Persistencia local y diseño adaptable.

Proyecto demostrativo creado con HTML, CSS, JavaScript y asistencia de inteligencia artificial.
